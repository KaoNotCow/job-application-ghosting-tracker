# Contributing

Thanks for helping make ghosting a little less invisible.

## The easiest ways to help
- **A company replied and the dashboard missed it?** Open a "It missed a reply" issue. Sender and subject only, never the email body.
- **Something broke?** Open a "Something broke" issue.
- **Have an idea or a question?** Start a Discussion.

## Code changes
1. Fork the repo and make your change on a branch.
2. If you edit `skills/job-app-ghost-tracker/SKILL.md`, rebuild the zip: `cd skills && zip -r ../job-app-ghost-tracker.zip job-app-ghost-tracker`.
3. Open a pull request and say what you changed and why.

## Ground rules
- No personal data in issues, pull requests or screenshots. Use the sample dashboard for screenshots.
- Keep the privacy promise: the skill stays read-only, and sharing stays opt-in.
